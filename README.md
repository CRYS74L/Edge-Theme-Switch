# Edge 浏览器整体外观一键切换

当前 Release：v1.1.0，提供自动切换版和纯手动版；颜色主题沿用 v1.0.1-dev.5（用户已确认顶栏与窗口按钮修改有效）。两版控制器的数值版本均为 `1.1.0.5`，显示名称分别为 `1.1.0-auto`、`1.1.0-manual`。

## Release 下载与选择

在 [v1.1.0 Release](https://github.com/CRYS74L/edge-browser-theme-toggle/releases/tag/v1.1.0) 中二选一：

| 安装包 | 功能 | 权限 |
| --- | --- | --- |
| `edge-browser-theme-toggle-v1.1.0-auto.zip` | 太阳按钮手动切换，并按当前 B站／YouTube 标签状态自动切换。 | `management`、`storage`、`scripting` 及指定视频网站权限。 |
| `edge-browser-theme-toggle-v1.1.0-manual.zip` | 只在点击太阳按钮时切换；不加载网页检测或自动模式模块。 | 仅 `management`，无网站权限。 |

每个 ZIP 都包含对应控制器、相同的深色主题 CRX、主题保留策略脚本和中文安装说明。两版使用同一控制器身份，不能同时加载；更换版本时移除旧控制器再加载所选包的 `packages/controller`，主题不必重复安装。`SHA256SUMS.txt` 提供两包的 SHA-256 校验值。仓库中的 `packages/controller/manifest.json` 默认仍是自动版。

执行 `npm run release:build` 可在 `.artifacts/releases/` 的新目录中生成两包及校验值。打包使用明确的文件清单，不包含签名私钥、浏览器配置、本机诊断或开发追踪。

这是一个只针对当前 Microsoft Edge 浏览器界面的开发者模式扩展。固定扩展图标后，单击一次即可在 Edge 的深色和内置浅色外观之间切换；本版配色针对顶栏、标签栏、工具栏和地址栏，不会反色网页内容，也不会修改 Windows 系统主题。

## 当前灰阶配色

顶栏使用 `#202020`，工具栏和非活动标签区域使用 `#3B3B3B`，地址栏使用 `#292929`。这三个基准色取自用户提供的 Edge 139 原生深色截图；活动标签与悬停颜色继续由 Edge 派生。

工具栏使用独立的 `toolbar-gray.png`，窗口框架使用 `frame-dark.png`。Edge 139 的垂直标签模式还会把工具栏图片用于顶栏，因此使用 `titlebar-dark.png` 覆盖图将顶栏恢复为 `#202020`。覆盖图同时用于活动与非活动窗口，宽 8192 DIP、高 64 DIP；窗口按钮常态背景透明，不再叠加深色方块，悬停与按下状态继续由 Edge 绘制。运行 `npm run theme:images` 可按主题清单重新生成三张纯色 PNG。

更新时需要把 `packages/theme-dark.crx` 拖入当前 Edge 的扩展页面，再重新加载“Edge 浏览器外观切换”。主题显示为 `1.0.1-dev.5-preview`；只重新加载控制器不会更新已经安装的主题图片。升级自动观看功能只需重新加载控制器并允许新增权限，无需重装 dev.5 主题。

## 最终实现

项目由一个解压缩控制器和一个主题包组成：

1. `packages/controller`：Manifest V3 工具栏控制器，使用 `management`、`storage`、`scripting` 和指定视频网站权限。
2. `packages/theme-dark`：无脚本的 Manifest V2 深色主题源目录；`packages/theme-dark.crx` 是使用固定签名密钥生成的安装包。

控制器首次通过 `chrome.management.getAll()` 按名称找到深色主题，之后缓存其身份，通过 `management.get()` 读取最新启用状态和版本，再调用 `chrome.management.setEnabled(themeId, enabled)`。缓存的主题不存在或身份不符时重新查找，避免正常切换时反复枚举所有扩展。启用主题就是深色外观，停用主题会回到 Edge 的内置浅色外观。主题 ID 不写死，因此 Edge 重启、服务工作进程回收或扩展重新加载后都能重新发现它。控制器与主题独立编号；控制器仍核验已确认的主题数值版本 `1.0.0.5`。

控制器同时同步工具栏图标：浅色外观使用深色太阳线性图标 `icon-light-*`，深色外观使用浅色太阳线性图标 `icon-dark-*`；两个状态的图形都是太阳，只改变线条颜色。Edge 启动、扩展安装、服务工作进程重载和每次切换都会按当前主题状态同步，不会在深色浏览器中继续显示深色图标。

太阳素材使用纯黑 `[0, 0, 0]` 与中性亮灰 `[245, 245, 245]`，所有尺寸按统一的 `max(1.15px, size / 14)` 笔宽生成；圆圈进一步放大至 `size × 0.225`，射线端点收短至 `size × 0.415`，保持与 Edge 线性工具栏图标一致的重量与比例。

深色主题包在 `theme.colors.toolbar_button_icon` 统一声明高对比工具栏图标色 `[245, 245, 245]`。这是 Edge 主题级颜色映射，会同时作用于返回、刷新、扩展、分屏、收藏夹、历史记录、下载等工具栏按钮及其悬停/按下状态，不通过脚本逐个改按钮，也不修改网页内容。

控制器运行时不包含 Native Messaging、本机组件、代理、回环端口、截图遮罩、后台常驻进程或设置页导航。项目有意只安装一个深色主题：停用它会恢复 Edge 的内置浅色状态。Edge 139 对普通安装的非当前主题有约 30 秒的回收机制；为保持 dev11 的点击链并解决这个浏览器级回收问题，主题清单声明 Edge 商店更新基地址，部署时先手动安装同一个签名 CRX，再用一次性 `normal_installed` 策略登记它。Edge 会把已安装的同 ID 主题提升为策略安装，控制器代码和点击时的可见行为都不变。

## 自动观看模式

- 只判断当前前台 Edge 窗口中正在选中的标签页；后台视频、其他窗口中的活动标签与直播间都不触发。当前标签：B 站 `/video/` 视频进入网页全屏、B 站数字路径或 `/blanc/房间号` 直播间、YouTube 视频进入影院模式时，自动启用现有深色主题。
- 退出对应模式、离开直播间、关闭页面或切到普通标签页时，只停用插件自动启用的深色；原本手动启用的深色保持。
- 两个符合条件的标签之间保持深色；切回仍处于观看模式的标签会重新自动启用。
- 手动按钮优先。自动深色时手动关闭，本段观看期间不会自动重开，离开标签再返回也保留该选择；退出并重新进入模式或换视频后重新判断。手动重新开启后，退出观看也保留深色。
- 主题对同一浏览器配置中的窗口共同生效；多窗口以最近前台的普通 Edge 窗口为准。切到其他应用时保留最近的浏览器状态。
- 后台服务休眠时，自动拥有权和本段手动选择保存在扩展 `storage.session` 中。浏览器完整重启／扩展重新加载会结束该会话；现存深色按已有外观保留，不擅自认定为自动开启。

只在 `www.bilibili.com`、`live.bilibili.com`、`www.youtube.com` 和 `youtube.com` 使用网站权限，不申请所有网站访问权限。网页脚本仅观察播放器状态，不改网页样式、播放进度、音量或 Cookie。`scripting` 用于给已经打开但尚无有效接收者的当前页面补注入观察脚本；不批量唤醒休眠标签页。本机状态诊断只保留最近的状态、标签编号和错误，不存视频 URL、标题或观看记录，不上传。

状态识别使用事件和 `MutationObserver`，没有定时轮询。dev.2 取消旧版报告前固定 80 ms 等待，播放器属性变化在下一微任务报告；属性监听只绑定播放器本身，页面节点监听用于发现延迟出现或替换的播放器及单页导航。已绑定播放器时，普通页面节点变化与直播弹幕不会触发状态采样。后台合并同轮事件，只复核一次前台窗口和标签，再读取当前页面状态；诊断写入移到切换完成后，不阻塞自动或手动操作。切换来源仍先保存，管理 API 状态仍回读确认。

dev.4 将图标和标题同步放到独立串行队列：主题应用并回读成功后，就允许下一次当前标签判断或手动切换继续，不等待图标更新。图标队列只保留最新待更新状态，等待正在执行的标题和图标全部结束后再同步最新状态；连续切换时不会依次绘制已经过期的中间图标。图标更新失败单独记录，不会把已经成功开启的自动深色错误认定为手动深色，退出观看仍能恢复浅色。手动点击不再等待临时的“切换中”标题写入。

本机 `watchLatency` 只记录最近一次实际自动切换的控制器版本、事件时间、上下文查询、主题状态查询、来源保存、管理 API 和 worker 耗时，以及存在当前标签事件时间戳时的端到端 API 耗时。端到端计时截止于主题状态回读完成；自 dev.4 起，worker 计时也不再等待图标同步，后者单独记为 `watchPresentation`。这些数值不代表屏幕完成绘制的时间。不记录 URL、页面标题，也不上传。已有 dev.5 主题的用户升级到 `1.1.0-auto` 无需重装主题或新增权限；手动版不使用这些观看状态诊断。

安装更新后在 Edge 扩展页重新加载“Edge 浏览器外观切换”，并允许新增网站权限。验证网页全屏／影院切换、切换普通标签页、手动覆盖，以及两个观看标签之间切换。

## 安装到当前 Edge

只在你正在使用的 Edge 中操作：

1. 打开 `edge://extensions`，开启“开发人员模式”。
2. 点击“加载解压缩的扩展”，选择项目中的 `packages/controller` 文件夹。
3. 把项目中的 `packages/theme-dark.crx` 拖入 `edge://extensions`，安装“Edge 外观切换 - 深色主题”。不要只加载 `packages/theme-dark` 解压缩目录。
4. 以管理员身份打开 PowerShell，运行一次：

   ```powershell
   powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install-theme-policy.ps1"
   ```

   脚本只写入 `HKLM\SOFTWARE\Policies\Microsoft\Edge` 下的 `ExtensionSettings` 一个值，默认使用 Edge 商店更新基地址，目标仅为本项目深色主题。出现 UAC 时由用户确认；若计算机组织策略禁止写入，需由管理员执行，不能由扩展权限代替。已有本项目策略时，脚本会安全地原位更新 URL；遇到其他策略内容仍会拒绝覆盖。
5. 打开 `edge://policy`，点击“重新加载策略”；若主题没有立即变成管理员安装，由用户自行重启 Edge 一次。
6. 将“Edge 浏览器外观切换”固定到工具栏，单击图标测试深色和浅色往返切换。

不要加载 `theme-light`，也不要运行旧版 `install-native-host.ps1`；最终版本已经不需要这些文件。若 Edge 中还留有旧版控制器或旧主题，先在 `edge://extensions` 移除，再按上面的控制器目录和 CRX 重新安装一次。

控制器重载后可以继续发现已存在的主题包。完成上面的策略登记后，即使浅色状态闲置超过 Edge 139 的主题回收窗口，主题包仍会保留；“系统”外观本身不提供这项保护。直接使用 `file://`、回环 HTTP 地址或其他自托管地址可能在未加入组织管理的 Edge 上显示 `[BLOCKED]`，不要使用这些地址。

## 状态提示

- `浅色模式`：当前 Edge 为深色，单击后回到浅色外观。
- `深色模式`：当前 Edge 为浅色，单击后启用深色主题。
- `主题组件未加载：请加载深色主题包`：仅表示 `packages/theme-dark` 未安装或已被移除。
- `未更改 Edge 外观：请查看扩展错误详情`：Edge 管理 API 返回了异常；不会伪报成功，也不会回退到本机组件。

如果用户自行安装了其他自定义主题，Edge 的浅色基准可能由该主题决定；本项目的契约是“启用本项目深色主题 / 停用后回到 Edge 当前的内置外观”。

## 卸载

如需完全移除，先在管理员 PowerShell 中运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File ".\scripts\install-theme-policy.ps1" -Remove
```

随后在当前 Edge 的 `edge://extensions` 中移除“Edge 浏览器外观切换”和“Edge 外观切换 - 深色主题”。回滚脚本只会删除它自己登记的 `ExtensionSettings` 值，不会删除其他 Edge 策略。

## 验证

在项目根目录执行：

```powershell
npm test
git diff --check
```

端到端验收应确认：

- 顶栏、标签栏和地址栏本身发生深浅变化，而不是网页 CSS 变化；
- 深色主题下工具栏和标签栏出现 `#3B3B3B` 灰色背景，地址栏有单独的 `#292929` 层次，工具栏图标保持高对比亮色；
- 连续点击多次都能往返；
- 重新加载控制器服务工作进程后仍能往返；
- 策略安装后浅色状态闲置超过 35 秒仍能再次点击切回深色；当前会话验证通过；
- 用户已手动重启 Edge，并确认重启后无需重新加载主题包或再次输入指令即可使用；
- Windows 主题设置、当前 Edge 窗口尺寸和已有标签页不被修改；
- 没有 `EdgeBrowserThemeToggle.NativeHost.exe` 或其他桥接进程。

## 项目结构

| 路径 | 作用 |
| --- | --- |
| `packages/controller` | 唯一的 MV3 工具栏控制器。 |
| `packages/theme-dark` | 无脚本深色浏览器主题源目录。 |
| `packages/theme-dark.crx` | 使用固定签名密钥生成的主题安装包，需手动拖入 Edge。 |
| `tests` | 管理 API、清单、架构和图标契约测试。 |
| `scripts/generate-icons.ps1` | 重新生成控制器图标的开发脚本。 |
| `scripts/install-theme-policy.ps1` | 一次性登记/回滚 Edge 139 的主题保留策略，默认使用 Edge 商店更新基地址。 |
