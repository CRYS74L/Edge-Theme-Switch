# Edge 浏览器主题切换

一个没有弹窗、没有设置页的 Edge 扩展组合：工具栏上的一个太阳/月亮图标即可在本项目提供的浅色与深色浏览器主题之间切换。

它只改变 Edge 浏览器框架的主题配色，不修改 Windows 的浅色/深色模式，也不改变系统其他应用的主题。

## 安装到当前 Edge

1. 在正在使用的 Edge 中打开 `edge://extensions`。
2. 打开“开发人员模式”。
3. 依次选择“加载解压缩的扩展”，加载以下三个 MV3 组件目录：

   - `packages/theme-light`
   - `packages/theme-dark`
   - `packages/controller`

4. 在 Edge 的“扩展”菜单中，将“Edge 浏览器主题切换”固定到工具栏；初始悬停提示为“单击切换 Edge 浏览器主题”。
5. 单击工具栏中的太阳/月亮图标：浅色主题会切到深色主题，深色主题会切回浅色主题；图标和悬停提示会同步更新。

控制器会在两个主题都存在时才切换。若缺少其中任一个，它会保留当前主题，并在图标悬停提示中说明需要重新加载两个主题包。

## 项目结构

| 路径 | 作用 |
| --- | --- |
| `packages/controller` | MV3 控制扩展；唯一的工具栏入口，不含弹窗。 |
| `packages/theme-light` | 静态 MV3 浅色 Edge 主题。 |
| `packages/theme-dark` | 静态 MV3 深色 Edge 主题。 |
| `tests` | 状态机、清单、图标和控制器行为测试。 |

## 验证

```powershell
npm test
```

测试覆盖主题方向、双主题异常状态、主题包缺失、快速连击、清单约束和图标资源。

## 卸载与恢复

在 `edge://extensions` 中移除这三个开发扩展；随后可在 Edge 的“外观”设置中选择默认主题或其他主题。
