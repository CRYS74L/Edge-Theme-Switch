# Edge 浏览器整体外观一键切换修复计划

目标：修复 v0.3.0-dev.13 在 Edge 139 中“深色→浅色后主题被移除、无法再切回深色”的故障，并交付不依赖颜色主题包、切换时不显示设置页的双向切换扩展。

## 约束

- 不修改 Windows 系统主题、网页内容、Edge Preferences 或用户已有标签。
- 不直接从扩展导航 `edge://settings/appearance`；扩展不创建或激活临时标签。
- 宿主只在同一 Edge 进程创建单标签屏外临时窗口，不创建新 Edge 进程，不改变用户现有窗口尺寸，不监听网络、不使用回环端口或常驻进程。
- 用户级注册表只保留本项目精确 Native Messaging 键；不写入 `HKLM`，不覆盖其他宿主。

## 当前 Edge 验收证据

真实点击不创建临时标签。宿主在同一 Edge 进程创建单标签窗口，将其移到屏外，再通过地址栏打开受限制的 `edge://` URL；用户当前窗口的活动文档和活动标签保持不变，宿主返回前关闭屏外窗口。

当前工作没有关闭或重启 Edge，所以重启后的真实点击不在本轮声称范围内；安装清单和注册表键是持久配置，用户可在需要时手动重启 Edge 做最后确认。
