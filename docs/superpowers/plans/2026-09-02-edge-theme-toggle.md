# Edge 浏览器整体外观一键切换修复计划

目标：修复 v0.3.0-dev.13 在 Edge 139 中“深色→浅色后主题被移除、无法再切回深色”的故障，并交付不依赖颜色主题包的双向切换扩展。

## 约束

- 不修改 Windows 系统主题、网页内容、Edge Preferences 或用户已有标签。
- 不直接从扩展导航 `edge://settings/appearance`；扩展只创建普通 `about:blank` 临时标签。
- 宿主只操作用户当前可见 Edge 窗口，不创建窗口、不改尺寸、不监听网络、不使用回环端口或常驻进程。
- 用户级注册表只保留本项目精确 Native Messaging 键；不写入 `HKLM`，不覆盖其他宿主。

## 实施状态

- [x] 通过真实 Edge 证据确认旧 `management` 架构的根因：停用唯一解压缩主题后，Edge 从管理列表移除主题。
- [x] 控制器改为 `nativeMessaging` + `storage`，使用普通临时标签、一次性宿主调用和可靠清理。

- [x] 通过 TDD 回归测试覆盖普通临时标签、宿主调用、失败清理、并发串行和启动状态恢复。

## 当前 Edge 验收证据

真实点击使用的临时标签由控制器创建并在宿主返回后删除，原活动标签随后恢复。宿主不使用 `chrome.tabs.create` 打开受限制的 `edge://` URL；它在 Edge UI 中打开设置，再操作现有外观单选控件。

当前工作没有关闭或重启 Edge，所以重启后的真实点击不在本轮声称范围内；安装清单和注册表键是持久配置，用户可在需要时手动重启 Edge 做最后确认。
